# 卤水体积分数 F1-only 口径审计

日期：2026-10-21

## 公式修正

默认卤水相对体积按周璐博士论文式 (3-10)--(3-13) 和 Cox--Weeks
式 (5)--(7) 直接计算：

\[
V_b=1000\frac{\rho_i S_i}{F_1(T)},\qquad
F_1(T)=\rho_bS_b(1+k).
\]

旧实现使用

\[
V_b=1000\frac{\rho_i S_i}{F_1(T)-\rho_iS_iF_2(T)},
\]

它等价于先在 Cox--Weeks 式 (15) 中令气体相对体积
\(V_a/V=0\)，再把得到的整体海冰密度代回式 (5)。该额外的零气体
体积闭合不属于论文给出的直接计算步骤，现已在代码中注释保留，不再参与默认计算。
