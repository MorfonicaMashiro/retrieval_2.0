温盐廓线、物理界面温度/介电和两种口径的八场景双路线闭环已审查；完整结果及下次任务入口见 [温盐廓线与物理界面审查及后续交接](温盐廓线与物理界面审查及后续交接.md)。

图 `tb_difference_vs_hi_hs_8_scenarios.png`（另有可编辑 SVG）直接读取 `../processed/tb_forward_table1_validation.csv`，纵轴为带符号的 `TBmodel − TBpaper`，没有重算前向模型。左、右面板分别以冰厚和雪深为横轴；点 I–VIII 是论文表 1 的八个理想场景。FYI 与 MYI 分别连线，线段仅帮助识别离散场景顺序，不是控制其他变量后的连续响应。

八个差值均为负，范围 −3.541 至 −0.404 K。数据剖析显示冰厚与雪深在这八个场景中的相关系数约为 0.92，故不能由这张图判定哪个变量造成亮温偏差。V 与 VI 的雪深同为 0.15 m，亮温差却相差约 1.06 K；两者冰厚同时变化。Vant 卤水体积分数标称范围在 I、II、III、V、VII 五个场景被超过，但偏差最大的 VIII 未越界，因此单靠卤水限幅也不能解释全部差异。

## 典型冬季条件下的 TB—冰厚曲线

`plot_tb_vs_ice_thickness_winter.m` 按周璐博士论文图 3.3 的场景设计，
使用当前 20 层前向模型绘制 FYI/MYI 在三种表面温度（−15、−25、
−35 °C）和三种雪厚下的亮温—冰厚曲线。FYI 雪厚为 1、10、20 cm，
冰厚范围 0–2 m；MYI 雪厚为 1、10、25 cm，冰厚范围 0–4 m。
论文没有给出图 3.3 的逐场景大气亮温修正，故图中明确采用
`atmosphereTBK=0`。由于 Cox--Weeks 的表值到 −30 °C，而论文图使用
−35 °C，绘图入口显式启用冷段 F1 多项式向 −35 °C 的外推；默认模型仍
不允许该外推。

输出目录 `tb_thickness_sensitivity/` 包含彩色 PNG、MATLAB FIG 和逐点
CSV。该图记录的是当前 20 层实现；已确认当前单向辐射递推不满足薄冰的
人工分层不变性，因此在修正下方介质栈有效反射传播后需要重画，不能把
本图当作作者代码级复现。
