# 海冰厚度—雪深联合反演流程图说明

对应[可编辑流程图](联合反演实现与实验分支.drawio)和[预览图](联合反演实现与实验分支.png)。本说明描述 `retrieval_matlab_ver` 中的 OIB–SMOS 联合反演 MATLAB 实现；当前执行口径以 2026-11-04 冻结的不截断、步长 3 主线为准。2026-10-29 的步长 1 论文复现结果只作为历史分支保留。`data/Zhou2020_reproduction` 是另一个卫星尺度数据链，目前没有直接并入主流程。

## 1. 数据到输入

| 阶段 | 实际实现 | 代码 |
| --- | --- | --- |

| OIB 落格 | 直接投影经纬度，`col=floor((x−xMin)/Δ)+1`，`row=floor((yMax−y)/Δ)+1`；OIB 数值不插值。 | `grid_resampling.PSP2EASE` |
| 配准 | 每个有效 SMOS 中心格取同日、中心及周围八个 EASE 格的 OIB 原始点。共同样本需四量有限、无开阔水/薄冰/灰冰标记、单一 FYI/MYI。九格内原始点直接平均，不先按小格平均；当前默认中心步长 3、相位 `[2 2]`，窗口互不重叠。 | `collocate_day.m` |

对第 `j` 个中心格的 `M_j` 个合格原始点，输入量为

\[
FB_{ice,p}=FB_{snow,p}-h_{s,p},\qquad
\bar q_j=M_j^{-1}\sum_{p=1}^{M_j}q_p,
\quad q\in\{FB_{snow},h_s,FB_{ice},h_i\}.
\]

反演只用 `TBobs`、冰型和选定的 `FBice` 或 `FBsnow`。`hi`、`hs` 留作验证。OIB 的 `FBice` 是雪面干舷减雪深的代理，不是独立 CryoSat-2 雷达干舷；OIB 的 `thickness` 也包含几何和静力平衡推算，不能称为完全独立真值。

## 2. 前向亮温 `F(hi,hs,isMYI)`

默认常数集中在 `retrieval_config.m`：`f=1.4 GHz`、`Tsurf=−30 °C`、`Tw=−1.8 °C`、`Sw=33 ppt`、`ρw/ρi/ρs=1024/915/320 kg m⁻³`、20 冰层+1 雪层、0:1:40° 与 H/V 平均、2.7 K 宇宙背景；大气项和经验偏移为 0。

1. **温度**：`tb_forward.m` 先算 FYI 体盐度或 MYI 垂向盐度，冰热导率
   \[
   k_i=2.034+0.13\bar S_i/T_{bulk,C},\quad
   T_{bulk,C}\approx(T_{surf}+T_w)/2.
   \]
   稳态热阻 `R=hs/ks+hi/ki`，热流 `q=(Tw−Tsurf)/R`，冰雪物理界面温度 `Tsi=Tsurf+q·hs/ks`。雪层和冰层的自发辐射温度均取**层中点**，物理界面温度与相邻层中点温度不得混同。
2. **盐度**：FYI 各层同盐，`S=max[1.5,6.08exp(−5.81hi)+7.409exp(−0.5228hi)] ppt`。MYI 对第 `k` 层中点 `z_k=(k−1/2)/N`，`S_k=1.6[1−cos(πz_k^{0.407/(z_k+0.573)})] ppt`。
3. **卤水与介电**：Cox–Weeks `Vb=1000 ρ_pureIce(T) S/F1(T)`，`F1` 按 `−2 °C`、`−22.9 °C` 分段。代码中三个 `F1` 三次多项式的降幂系数分别为 `(0.21454,0.58402,−18.407,−0.041221)`、`(−0.01074,−0.6397,−22.45,−4.732)`、`(0.7160,55.27,1309,9899)`。海冰 Vant 关系 `ε_i=a1+a2Vb+i(a3+a4Vb)`；FYI 系数为 `(3.10,0.0084,0.037,0.00445)`，MYI 为 `(3.10,0.0084,0.003,0.00435)`。Tiuri 干雪式为 `ε'_s=1+0.7ρ_r+0.7ρ_r²`、`ε''_s=1.59×10⁶(0.52ρ_r+0.62ρ_r²)(f⁻¹+1.23×10⁻¹⁴√f)exp(0.036T)`。Klein–Swift 海水式先计算 `εraw=4.9+(εstatic−4.9)/(1+iωτ)−iσ/(ωε0)`，再将负虚部改记为内部使用的正损耗虚部，即 `εwater=Re(εraw)+i[-Im(εraw)]`；`εstatic/τ/σ` 的温盐经验式在 `tb_forward.m`。基线对 `Vb≥70‰` **标记超经验适用域但不截断**。
4. **层光学**：对角度 `θ0` 与 H/V 极化，`q_j=√(ε_j−sin²θ0)`；Fresnel 振幅 `r_H=(q_1−q_2)/(q_1+q_2)`、`r_V=(ε_2q_1−ε_1q_2)/(ε_2q_1+ε_1q_2)`，功率反射率 `R=|r|²`。层透射 `τ_j=exp[−2(2πf/c)|Im(q_j)|d_j]`。同一种材料的数值分层界面令 `R=0`；默认物理界面使用相邻层中点介电常数。
5. **Burke 递推**：`burke_stack.m` 自海水边界 `U_{n+1}=T_w(K)` 向上，令 `A_j=(1−τ_j)(1+R_jτ_j)`，再算 `U_j=T_j(K)A_j+(1−R_j)τ_jU_{j+1}`。顶部辐射为 `(1−Rtop)U_1`。把所有温度源设为 1 作同样递推，得到有效发射率 `e_eff`；每个角度与极化再加 `(1−e_eff)×2.7 K`。最后对 0–40° 与 H/V **算术平均**，并加默认 0 的大气项和偏移。反演样本已排除开阔水/水道，所以此链没有面积混合项。

这是一套根据公开公式重建的可审计前向模型。论文没有给出原作者完整数值离散代码，也没有明确本地源产品到其 EASE/L4 输入的唯一重采样方法。

## 3. 两条反演与精度评定

令 `g(hs)=F(hi(hs),hs,type)−TBobs`，`ρw>ρi>ρs`。`invert_pair.m` 对每条配对分别求：

| 路线 | 静力平衡约束 | 搜索 |
| --- | --- | --- |
| `TB+FBice` | `hi=(ρw·FBice+ρs·hs)/(ρw−ρi)` | 雪深 0–1 m，4 cm 初扫；每个变号区间二分。 |
| `TB+FBsnow` | `hi=[ρw·FBsnow−(ρw−ρs)hs]/(ρw−ρi)`，且 `FBice=FBsnow−hs≥0` | 雪深 0–`min(1 m,FBsnow)`，1 cm 全扫；所有变号区间分别二分并保存多根。 |

两路均限制 `0≤hi≤10 m`。扫描点直接满足 `|g|≤0.01 K` 时可接受；二分到 `|g|≤0.01 K` 或雪深区间宽 `≤10⁻⁵ m`，最多 60 次；写入解前再次检查 `|g|≤0.01 K`。雪面干舷有双根时，验证默认选较小雪深根，第二根单独保存。无根保留状态，不用外插值充作解。

`main_inversion.m` 使用同一配对的 OIB 平均 `hi/hs` 验证反演；模拟 TB 验证值则单独计算 `F(hi_OIB,hs_OIB,type)`。`fit_retrieval.m` 只对参照和估计都有限的配对计算 `n`、`bias=mean(y−x)`、`RMSE=√mean[(y−x)²]`、自由斜率最小二乘 `y=ax+b`、相关系数 `r` 和 `R²=r²`。总体、逐年、`nOIB` 前 5%、`|TBOIB−TBobs|≤1.5 K` 子集分别报告；1.5 K 子集用了 OIB 验证量，因此**只是诊断子集，不是部署时可用的反演前筛选条件**。原始浮点值、配对标识、根数、掩膜和具名配置均保存，避免提前舍入或不同口径结果互相覆盖。比较 A/B/Aw/Bw 时须固定同一批 733 个 stride=3 窗口；stride=1 的 6,542 条配对只作历史参照，不能把不同样本集合的 RMSE 变化全归因于算子。
